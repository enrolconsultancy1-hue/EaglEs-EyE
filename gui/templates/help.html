Getting Started

EaglEs EyE creates a Project Twin — a machine-readable snapshot of your software project. Follow these steps to create your first twin.

  1. Click Connect Project and enter your project folder path
  2. Click Scan Project to analyse the folder
  3. Click Create Twin to generate the Project Twin
