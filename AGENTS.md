# EaglEs EyE AI contributor instructions

Before inspecting, proposing, or changing code, read
[`AI_TWIN_CONSTITUTION.md`](AI_TWIN_CONSTITUTION.md) completely.

Then read these root documents in order:

1. [`ARCHITECTURE.md`](ARCHITECTURE.md) — technical boundaries and services.
2. [`PROJECT_STATUS.md`](PROJECT_STATUS.md) — completed work and limitations.
3. [`NEXT_TASK.md`](NEXT_TASK.md) — the immediate approved direction.
4. [`BENCHMARKS.md`](BENCHMARKS.md) — measured evidence and performance.

The constitution is the permanent mission and design constraint. Preserve
working architecture, make observations passive, base conclusions on observable
evidence, and extend existing services rather than replacing them.
